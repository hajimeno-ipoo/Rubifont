使い方・ライセンス

Rubifont Sans Regular 0.3.0

漢字の上にひらがな、登録した英単語の上にカタカナを表示するフォントです。

Macで使う

  1. インストール用フォント（OTF）をダウンロードします。
  2. OTFファイルを開き、Font Bookでインストールします。
  3. 使いたいアプリで、フォントを「Rubifont Sans」に指定します。

横書き・Regularの一種類です。アプリのOpenType対応や行間設定によって表示が異なります。

Webサイトで使う

Web用フォント（WOFF2）をページと同じフォルダへ置き、次のように指定します。

@font-face {
  font-family: 'Rubifont Sans';
  src: url('./RubifontSans-Regular.woff2') format('woff2');
  font-weight: 400;
}
.reading {
  font-family: 'Rubifont Sans', sans-serif;
  font-weight: 400;
  line-height: 1.9;
}

読みが切れないよう、行間を広めに設定してください。font-feature-settings: 'ss01' 1で日英の読みを非表示にできます。

対応範囲

英語は同梱の一覧にある語が対象です。小文字・頭だけ大文字・全大文字の表記に対応しています。未知語、任意の大小文字混在、文脈による読み分けは対象外です。カタカナは発音の目安です。

送り仮名による読み分けを補助するJavaScriptは、この配布物には含みません。

本文の文字データは元のままです。単語が別の要素や書式に分かれる場合、フォントから見える範囲も分かれます。
